🖼️ 图库

使用说明
  1. 打开 GitHub → Settings → Developer settings → Personal access tokens 生成 Token。
    · Fine-grained Token：选中仓库 xunyue，权限 Contents = Read and write；
    · Classic Token：勾选 repo 权限。
  2. 把 Token 粘贴到上方输入框，点「保存」，再点右上角「刷新图库」加载已有文件。
  3. 点击或拖拽文件到上传区即可上传，上传成功后外链为 https://xunyuman.github.io/xunyue/文件名。
  4. 卡片上的「复制」按钮复制的就是上面这个 Pages 外链；「打开」在新标签页预览；「删除」会自动带上文件的 sha。
  5. 提示：GitHub Pages 有构建/缓存延迟，刚上传的文件外链可能要等几十秒才能访问；图库缩略图走 raw.githubusercontent.com，可立即预览。
